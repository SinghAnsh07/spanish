# 🌸 Estudio de Español – BESP101L Interactive Testing Studio

An aesthetic, responsive digital worksheet and testing platform for **Spanish I (BESP101L)**, built with soft baby-pink & marshmallow-white pastel aesthetics, sleek pill controls, and instant grading with pedagogical grammar explanations.

🌐 **Live Website**: [https://singhansh07.github.io/spanish/](https://singhansh07.github.io/spanish/)

---

## ✨ Features

- **🌸 Soft Pastel Aesthetic**: Designed with gentle baby pink (`#f472b6`, `#fdf2f8`), soft rose accents, and pure marshmallow white surfaces.
- **✨ Clean & Non-Bloated**: Sleek pill-shaped buttons, minimal borders, subtle focus states, and zero clutter.
- **✅ Studied Status Tracking**:
  - Mark any worksheet as **Studied** (`✓ Studied`) or **To Study** (`○ Mark as Studied`) with a single click.
  - Recognizes documents moved into the `done/` folder automatically.
  - Persists your progress seamlessly in browser `localStorage`.
  - Filter hub by `All Documents`, `✅ Studied`, or `⏳ To Study` with live counters and study progress percentage bar.
  - Mark or unmark a document right from the active test or post-test results review screen.
- **🎓 Practice Previous Year Papers (FAT)**:
  - Practice real university **Final Assessment Test (FAT)** papers paper-wise from `Spanish FAT.pdf`.
  - Official 100-mark evaluation with predicted university grades (**S Grade**, **A Grade**, **B Grade**, etc.).
  - Real exam sections: Articles, Regular & Irregular Conjugations, Gustar/Interesar error corrections, Estar + Gerundio, Ser vs Estar vs Tener, Directions, and Reading Comprehensions.
- **📁 Document Selection Hub**: Filter and choose among all **15 course documents & worksheets** or browse by grammar topic.
- **✍️ Digital Testing Mode**:
  - Multiple Choice Questions (MCQ) with intuitive radio pills.
  - True or False (Verdadero / Falso).
  - Fill in the blanks with accent-smart input normalization.
  - Floating Spanish Accents Toolbar (`á`, `é`, `í`, `ó`, `ú`, `ñ`, `¿`, `¡`) for typing effortlessly on any keyboard.
  - Real-time progress bar.
- **📊 Instant Scoring & Detailed Review**:
  - Score percentage, fractions (`18 / 20`), and performance badges.
  - Filter results by *All*, *Incorrect Only*, or *Correct Only*.
  - Compares your answer with the correct answer.
  - **💡 Clear Grammar Explanations** for every single question explaining the grammatical rules, conjugation logic, and vocabulary nuance.

## 🚀 How to Run Locally

Simply clone the repository and open `index.html` in any modern web browser:

```bash
git clone https://github.com/SinghAnsh07/spanish.git
cd spanish
# Open index.html in your browser or run a simple local server
python -m http.server 8000
```
Visit `http://localhost:8000` to practice!
